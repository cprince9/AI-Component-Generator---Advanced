GenU: AI Component Generator 🤖✨
Welcome to GenU, a powerful and intuitive web application that leverages the Google Gemini API to generate UI components from natural language descriptions. Describe the component you need, and GenU will write the code for you in real-time.

🌟 Key Features
AI-Powered Generation: Utilizes the Google Gemini API to understand your requirements and generate clean, production-ready code.

Multiple Frameworks: Supports various web technologies including HTML/CSS, Tailwind CSS, React, and more.

Live Preview: Instantly see a visual preview of your generated component right in the browser.

Integrated Code Editor: View, edit, and copy the generated code with a built-in Monaco Editor that features syntax highlighting.

Real-Time Streaming: Watch the AI write the code in real-time for an interactive and engaging experience.

Responsive Design: A modern, sleek, and fully responsive interface with a dark mode theme.

🛠️ Tech Stack
Frontend: React

Build Tool: Vite

Styling: Tailwind CSS

AI Model: Google Gemini API

Code Editor: Monaco Editor

Routing: React Router

UI Components: React Select, React Icons

🚀 Getting Started
Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

Prerequisites
Node.js (version 18.x or higher is recommended)

npm (usually comes with Node.js)

A Google Gemini API Key. You can get one for free from Google AI Studio.

Installation & Setup
Clone the Repository

git clone [https://github.com/cprince9/Generate_UI.git](https://github.com/cprince9/Generate_UI.git)
cd Generate_UI

Install Dependencies

npm install

Set Up Environment Variables

Create a new file named .env.local in the root of your project.

Add your Google Gemini API key to this file:

VITE_GEMINI_API_KEY="YOUR_API_KEY_HERE"

Run the Development Server

npm run dev

Open http://localhost:5173 (or the URL shown in your terminal) to view the application in your browser.

💡 How to Use
Describe Your Component: In the text area, describe the UI component you want to create (e.g., "a responsive login form with a social media login option").

Select a Framework: Choose your desired technology stack from the dropdown menu.

Generate: Click the "Generate" button.

View & Use: Watch the code stream in the editor. You can switch to the "Preview" tab to see how it looks, and use the toolbar to copy or download the code.
