# GenU: AI Component Generator 🤖✨

Welcome to **GenU**, a powerful and intuitive web application that leverages the **Google Gemini API** to generate UI components from natural language descriptions.  
Simply describe the component you need, and GenU will write the code for you in real-time.

---

## 🌟 Key Features

- **AI-Powered Generation**: Utilizes the Google Gemini API to understand your requirements and generate clean, production-ready code.  
- **Multiple Frameworks**: Supports HTML/CSS, Tailwind CSS, React, and more.  
- **Live Preview**: Instantly see a visual preview of your generated component right in the browser.  
- **Integrated Code Editor**: Built-in **Monaco Editor** with syntax highlighting to view, edit, and copy code.  
- **Real-Time Streaming**: Watch the AI write the code live for an engaging experience.  
- **Responsive Design**: Modern, sleek, and fully responsive interface with **Dark Mode** support.  

---

## 🛠️ Tech Stack

- **Frontend**: React  
- **Build Tool**: Vite  
- **Styling**: Tailwind CSS  
- **AI Model**: Google Gemini API  
- **Code Editor**: Monaco Editor  
- **Routing**: React Router  
- **UI Components**: React Select, React Icons

## 🚀 Getting Started

Follow these steps to set up the project locally:

### ✅ Prerequisites
- **Node.js** (v18.x or higher recommended)  
- **npm** (comes with Node.js)  
- **Google Gemini API Key** → [Get one here](https://ai.google.dev/)  

### 📥 Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/cprince9/Generate_UI.git
   cd Generate_UI

2. **Install Dependencies**
   ```bash
   npm install

3. **Set Up Environment Variables**
   ```bash
   Create a new file named .env.local in the project root.
   Add your Gemini API key:
       VITE_GEMINI_API_KEY="YOUR_API_KEY_HERE"

2. **Install Dependencies**
   ```bash
   npm install

2. **Run Project**
   ```bash
   npm run dev
